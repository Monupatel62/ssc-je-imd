### Q1. [SSC Scientific Assistant CS 2017]
**The implementation of the LFU and the MFU page replacement algorithm is very:**
- (A) Simple and cheap
- (B) Expensive (rarely used)
- (C) Same as FIFO
- (D) Efficient as LRU

**Answer:** (B) Expensive (rarely used)  
**Explanation:** LFU (Least Frequently Used) and MFU (Most Frequently Used) page replacement algorithms require maintaining frequency counts for all pages, making them expensive to implement and rarely used in practice.

### Q2. [SSC Scientific Assistant CS 2017]
**In Round Robin CPU scheduling, as the time quantum is increased to infinity, it approaches:**
- (A) SJF (Shortest Job First)
- (B) FCFS (First Come First Serve)
- (C) Priority scheduling
- (D) Multilevel Queue scheduling

**Answer:** (B) FCFS (First Come First Serve)  
**Explanation:** In Round Robin scheduling, when the time quantum becomes very large (approaches infinity), each process runs to completion without being preempted, making it equivalent to FCFS scheduling.

### Q3. [SSC Scientific Assistant CS 2017]
**What is the time complexity of Binary Search?**
- (A) O(n)
- (B) O(n²)
- (C) O(log n)
- (D) O(n log n)

**Answer:** (C) O(log n)  
**Explanation:** Binary search divides the search space in half with each comparison. For n elements, it takes at most log₂(n) comparisons, giving O(log n) time complexity.

### Q4. [SSC Scientific Assistant CS 2017]
**Which sorting algorithm has the best average case time complexity?**
- (A) Bubble sort — O(n²)
- (B) Selection sort — O(n²)
- (C) Merge sort — O(n log n)
- (D) Insertion sort — O(n²)

**Answer:** (C) Merge sort — O(n log n)  
**Explanation:** Among common sorting algorithms, Merge Sort, Quick Sort (average), and Heap Sort have O(n log n) time complexity. Bubble, Selection, and Insertion sort have O(n²) average case.

### Q5. [SSC Scientific Assistant CS 2017]
**Dijkstra's algorithm is used for:**
- (A) Finding the minimum spanning tree
- (B) Finding the shortest path from a source to all other vertices in a weighted graph
- (C) Topological sorting
- (D) Depth-first search

**Answer:** (B) Finding the shortest path from a source to all other vertices  
**Explanation:** Dijkstra's algorithm finds the shortest path from a single source vertex to all other vertices in a weighted graph with non-negative edge weights.

### Q6. [SSC Scientific Assistant CS 2017]
**Which algorithm design technique is used in Merge Sort?**
- (A) Greedy method
- (B) Divide and Conquer
- (C) Dynamic Programming
- (D) Backtracking

**Answer:** (B) Divide and Conquer  
**Explanation:** Merge Sort uses the Divide and Conquer technique — it divides the array into two halves, recursively sorts each half, and then merges them. Time: O(n log n), Space: O(n).

### Q7. [SSC Scientific Assistant CS 2017]
**Which of the following is true about Dynamic Programming?**
- (A) It solves problems by making locally optimal choices at each step
- (B) It breaks a problem into overlapping subproblems and stores their solutions to avoid redundant computation
- (C) It always uses backtracking
- (D) It only works for sorting algorithms

**Answer:** (B) It breaks a problem into overlapping subproblems and stores their solutions  
**Explanation:** Dynamic Programming solves problems by breaking them into overlapping subproblems, solving each once and storing results (memoization/tabulation). Examples: Fibonacci, Longest Common Subsequence, 0/1 Knapsack.
