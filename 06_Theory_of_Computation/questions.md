### Q1. [SSC Scientific Assistant CS 2017]
**Which of the following statements is true about Finite Automata?**
- (A) DFA and NFA accept different classes of languages
- (B) Every NFA can be converted to an equivalent DFA
- (C) DFA requires less states than NFA for all languages
- (D) NFA cannot accept regular languages

**Answer:** (B) Every NFA can be converted to an equivalent DFA  
**Explanation:** DFA (Deterministic Finite Automaton) and NFA (Non-Deterministic Finite Automaton) are equivalent in power — every NFA can be converted to an equivalent DFA (subset construction algorithm), and vice versa. Both accept exactly the class of regular languages.

---

### Q2. [SSC Scientific Assistant CS 2017]
**Regular languages are accepted by:**
- (A) Pushdown automata
- (B) Turing machines only
- (C) Finite automata
- (D) Linear bounded automata

**Answer:** (C) Finite automata  
**Explanation:** Regular languages are recognized/accepted by finite automata (DFA/NFA). They can also be described by regular expressions and generated by regular grammars (Type 3 in Chomsky hierarchy).

---

### Q3. [SSC Scientific Assistant CS 2017]
**Context-free languages are recognized by:**
- (A) Finite automata
- (B) Pushdown automata (PDA)
- (C) Turing machines
- (D) Regular expressions

**Answer:** (B) Pushdown automata (PDA)  
**Explanation:** Context-free languages (CFLs) are recognized by Pushdown Automata (PDA). CFLs are described by context-free grammars (CFGs) and are used to describe the syntax of programming languages.

---

### Q4. [SSC Scientific Assistant CS 2017]
**Which of the following is true about regular expressions?**
- (A) Every regular expression can be converted to a finite automaton
- (B) Regular expressions can describe context-free languages
- (C) Regular expressions cannot describe the language a^n b^n
- (D) Both A and C

**Answer:** (D) Both A and C  
**Explanation:** Regular expressions can be converted to finite automata (and vice versa) — they describe the same class (regular languages). The language {a^n b^n | n ≥ 0} is NOT regular (proven by the pumping lemma for regular languages).

### Q5. [SSC Scientific Assistant CS 2017]
**In the Chomsky hierarchy, which is the most powerful model of computation?**
- (A) Finite automata
- (B) Pushdown automata
- (C) Linear bounded automata
- (D) Turing machine

**Answer:** (D) Turing machine  
**Explanation:** The Chomsky hierarchy (from least to most powerful): Finite Automata (Type 3) → Pushdown Automata (Type 2) → Linear Bounded Automata (Type 1) → Turing Machine (Type 0). Turing machines are the most powerful.

### Q6. [SSC Scientific Assistant CS 2017]
**The halting problem is:**
- (A) Decidable for all Turing machines
- (B) Undecidable — no algorithm can determine whether any arbitrary Turing machine halts on a given input
- (C) Solvable by finite automata
- (D) Related only to pushdown automata

**Answer:** (B) Undecidable  
**Explanation:** The Halting Problem (given a Turing machine M and input w, does M halt on w?) is undecidable — proven by Alan Turing using a proof by contradiction/diagonalization. No general algorithm can solve it.
