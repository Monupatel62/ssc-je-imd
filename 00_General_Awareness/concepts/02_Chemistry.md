## 3. GREENHOUSE GASES

### Greenhouse gases HAIN:
- CO₂ (Carbon Dioxide)
- CH₄ (Methane)
- N₂O (Nitrous Oxide)
- H₂O (Water Vapor)
- O₃ (Ozone)

### Greenhouse gas NAHI hai:
> **N₂ (Nitrogen)** ✅ — atmosphere ka 78% hai but greenhouse nahi

> **Trick:** "Nitrogen = Normal gas, greenhouse nahi"

## 4. ACIDS, BASES, SALTS

| Type | pH | Example |
|---|---|---|
| Strong Acid | 0-3 | HCl, H₂SO₄ |
| Weak Acid | 4-6 | Vinegar, Lemon |
| **Neutral** | **7** | Pure Water |
| Weak Base | 8-10 | Baking soda |
| Strong Base | 11-14 | NaOH, KOH |

### Buffer Solution ✅ (2017 mein aaya)
> Buffer solution mein kuch add karne se **pH mein significant change NAHI aata**
> **Trick:** "Buffer = Shock absorber — kuch nahi badlta"
