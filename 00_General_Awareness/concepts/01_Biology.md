## 1. VITAMINS

| Type | Vitamins | Property |
|---|---|---|

| **Water Soluble** | **B complex, C** | Roz lene padte hain, store nahi hote |

### Vitamins Table
| Vitamin | Chemical Name | Deficiency Disease | Source |
|---|---|---|---|
| A | Retinol | **Night Blindness** | Carrot, Milk |
| B1 | Thiamine | **Beriberi** | Whole grains |
| B2 | Riboflavin | Mouth sores | Milk, Eggs |
| B3 | Niacin | **Pellagra** (3D) | Meat, Fish |
| B9 | Folic Acid | Neural tube defect | Green vegetables |
| B12 | Cobalamin | **Pernicious Anaemia** | Meat, Dairy |
| C | Ascorbic Acid | **Scurvy** | Amla, Nimbu |
| D | Calciferol | **Rickets** (children), Osteomalacia (adults) | **Sunlight** ☀️ |
| E | Tocopherol | Muscle weakness | Nuts, Seeds |
| K | Phylloquinone | **Blood clotting nahi hota** | Green leafy vegetables |

> **Trick:** "Andha Baap Citrus Dhoop Ka"
> A=Andha(Night Blindness), B12=Baap(Blood/Anaemia), C=Citrus(Scurvy), D=Dhoop(Rickets), K=Ka(Khoon clotting)

## 2. WHITTAKER'S 5 KINGDOMS

| Kingdom | Features | Examples |
|---|---|---|
| **Monera** | No nucleus (Prokaryote) | Bacteria, Cyanobacteria |
| **Protista** | Single cell, nucleus hai (Eukaryote) | Amoeba, Paramecium |
| **Fungi** | Cell wall hai, **photosynthesis NAHI** | Mushroom, Yeast |
| **Plantae** | Cell wall hai, **photosynthesis HOTI HAI** | Trees, Grass |
| **Animalia** | No cell wall, move kar sakte hain | Fish, Bird, Human |

> **Trick:** "Mere Papa Funny Padhate Aate" = Monera, Protista, Fungi, Plantae, Animalia

### Linnaeus vs Whittaker
| | Linnaeus | Whittaker |
|---|---|---|
| Kingdoms | 2 | 5 |
| Year | 1758 | 1969 |

## 5. PHOTOSYNTHESIS

### Formula
> **6CO₂ + 6H₂O + Sunlight → C₆H₁₂O₆ + 6O₂**
> Carbon Dioxide + Water + Sunlight → Glucose + Oxygen

### Key Facts
| Fact | Detail |
|---|---|
| Kahan hoti hai | **Chloroplast** mein |
| Kaun karta hai | **Chlorophyll** (green pigment) |
| Plants green kyun | Chlorophyll ki wajah se |
| CO2 kahan se | Stomata se |
| O2 kahan jaata hai | Stomata se bahar |

### Photosynthesis vs Respiration
| | Photosynthesis | Respiration |
|---|---|---|
| CO₂ | Absorb | Release |
| O₂ | Release | Absorb |
| Food | Banata hai | Consume karta hai |
