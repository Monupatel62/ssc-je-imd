### Q1. [22 Nov 2017 / 23 Nov 2017 / 24 Nov 2017]
**Which of the following is NOT capable of storing binary data?**
- (A) Flip-flop
- (B) Register
- (C) Switch
- (D) Counter

**Answer:** (C) Switch  
**Explanation:** A switch is not capable of storing data. Flip-flops, registers, and counters all store binary information.

---

### Q2. [SSC Scientific Assistant CS 2017]
**A register capable of shifting its binary information either to the right or to the left is called:**
- (A) Counter register
- (B) Shift register
- (C) Accumulator
- (D) Program counter

**Answer:** (B) Shift register  
**Explanation:** A shift register is a type of digital circuit that can shift (move) its stored data either to the left or right.

---

### Q3. [SSC Scientific Assistant CS 2017]
**If the main memory is of 8K bytes and the cache memory is 2K bytes, how many bits are needed for each cache memory word?**
- (A) 8 bits
- (B) 12 bits
- (C) 16 bits
- (D) 32 bits

**Answer:** (C) 16 bits  
**Explanation:** Main memory = 8K bytes = 8 × 1024 × 8 bits = 2^16 bits. Therefore, 16 bits are needed for each cache memory word.

---

### Q4. [SSC Scientific Assistant CS 2017]
**A computer with a 32-bit wide data bus uses 4K × 8 static RAM chips. The minimum memory that can be built using these chips is:**
- (A) 4 KB
- (B) 8 KB
- (C) 16 KB
- (D) 32 KB

**Answer:** (C) 16 KB  
**Explanation:** Each chip has 8-bit data I/O. For a 32-bit data bus, we need 32/8 = 4 chips. Minimum memory = 4 × 4KB = 16KB.

### Q5. [SSC Scientific Assistant CS 2017]
**Which of the following is a semi-conductor memory?**
- (A) Magnetic tape
- (B) Magnetic disk
- (C) RAM and ROM
- (D) Compact disk

**Answer:** (C) RAM and ROM  
**Explanation:** Semiconductor memories are RAM (Random Access Memory) and ROM (Read-Only Memory). Magnetic tapes, discs, and CDs use non-semiconductor technology.

### Q6. [SSC Scientific Assistant CS 2017]
**Which of the following have the fastest access time?**
- (A) Magnetic tape
- (B) Magnetic disk
- (C) Semiconductor memory
- (D) Compact disk

**Answer:** (C) Semiconductor memory  
**Explanation:** Semiconductor memories have the fastest access time. Magnetic and optical storage have relatively higher access times.

### Q7. [SSC Scientific Assistant CS 2017]
**Which of the following statements is true about Non-Maskable Interrupts?**
- (A) They can be disabled by the programmer
- (B) Non-maskable interrupts are reserved for events such as unrecoverable memory errors
- (C) They have lower priority than maskable interrupts
- (D) They are used for I/O device communication only

**Answer:** (B) Non-maskable interrupts are reserved for events such as unrecoverable memory errors  
**Explanation:** Non-maskable interrupts (NMI) cannot be disabled and are reserved for critical hardware failures such as unrecoverable memory errors.

---

### Q8. [SSC Scientific Assistant CS 2017]
**Content of the program counter is added to the address part of an instruction to obtain effective address in:**
- (A) Relative addressing mode
- (B) Indirect addressing mode
- (C) Index addressing mode
- (D) Base register addressing mode

**Answer:** (A) Relative addressing mode  
**Explanation:** In relative addressing mode, the effective address is obtained by adding the program counter (PC) content to the address field of the instruction.

---

### Q9. [SSC Scientific Assistant CS 2017]
**A stack-organized computer uses instruction of:**
- (A) Two-address
- (B) One-address
- (C) Zero-address
- (D) Three-address

**Answer:** (C) Zero-address  
**Explanation:** Stack-organized computers use zero-address instructions because operands are implicitly fetched from the top of the stack.

---

### Q10. [SSC Scientific Assistant CS 2017]
**The three major methods of allocating disk space that are in use are:**
- (A) Contiguous, linked, and indexed allocation
- (B) Paged, segmented, and direct allocation
- (C) Sequential, random, and direct allocation
- (D) Fixed, dynamic, and variable allocation

**Answer:** (A) Contiguous, linked, and indexed allocation  
**Explanation:** The three major file allocation methods used in file systems are contiguous allocation, linked allocation, and indexed allocation.
